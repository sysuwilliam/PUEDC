# 测试结果

右后轮RR：板1A；悬空时，50不动，75动；需要invert

右前轮RF：板1B；悬空时，100不完全动，125动；需要invert

左后轮LR：板2A；悬空时，50不动，75动；不需要invert

左前轮LF：板2B；悬空时，75不完全动，100动；不需要invert

00停止是平滑的，11停止是迅速而干净的

## 测试 1：自动正反转循环

用途：最基础地确认电机能正转、停、反转、停。

```
#include "ti_msp_dl_config.h"
#include "motor.h"

static void delay_ms(uint32_t ms)
{
    while (ms--) {
        delay_cycles(32000);
    }
}

int main(void)
{
    SYSCFG_DL_init();

    Motor_Init();

    while (1) {
        MotorA_SetSpeed(200);
        delay_ms(1500);

        MotorA_Stop(MOTOR_STOP_00);
        delay_ms(1000);

        MotorA_SetSpeed(-200);
        delay_ms(1500);

        MotorA_Stop(MOTOR_STOP_00);
        delay_ms(1000);
    }
}
```

## 测试 2：按键找最低启动 PWM

用途：按一下推进一步，测试 +PWM / 停 / -PWM / 停，用于找最低启动速度。

你已经测到：

50 不行
75 可以
100 可以

这个以后给其他电机也可以复用。

```
#include "ti_msp_dl_config.h"
#include "motor.h"
#include "key.h"

#define TEST_PWM_MIN   50
#define TEST_PWM_MAX   500
#define TEST_PWM_STEP  25

static void test_pwm_next_step(void)
{
    static int16_t test_pwm = TEST_PWM_MIN;
    static uint8_t phase = 0;

    switch (phase) {
        case 0:
            MotorA_SetSpeed(test_pwm);
            break;

        case 1:
            MotorA_Stop(MOTOR_STOP_00);
            break;

        case 2:
            MotorA_SetSpeed(-test_pwm);
            break;

        case 3:
            MotorA_Stop(MOTOR_STOP_00);

            test_pwm += TEST_PWM_STEP;
            if (test_pwm > TEST_PWM_MAX) {
                test_pwm = TEST_PWM_MIN;
            }
            break;

        default:
            MotorA_Stop(MOTOR_STOP_00);
            phase = 0;
            return;
    }

    phase++;
    if (phase >= 4) {
        phase = 0;
    }
}

int main(void)
{
    SYSCFG_DL_init();

    Motor_Init();

    while (1) {
        if (Key1_PressedOnce()) {
            test_pwm_next_step();
        }
    }
}
```

按键顺序：

+50 → 停 → -50 → 停
+75 → 停 → -75 → 停
+100 → 停 → -100 → 停
……
直到 500 后回到 50

如果你想回到粗测，把步进改成：

#define TEST_PWM_STEP  100

## 测试 3：停止模式对比

用途：比较 00停止 和 11停止。

你已经测出：

00：平滑停止
11：迅速干净停止
#include "ti_msp_dl_config.h"
#include "motor.h"
#include "key.h"

```
static void test_stop_mode_next_step(void)
{
    static uint8_t step = 0;

    switch (step) {
        case 0:
            MotorA_SetSpeed(300);
            break;

        case 1:
            MotorA_Stop(MOTOR_STOP_00);
            break;

        case 2:
            MotorA_SetSpeed(300);
            break;

        case 3:
            MotorA_Stop(MOTOR_STOP_11);
            break;

        case 4:
            MotorA_SetSpeed(-300);
            break;

        case 5:
            MotorA_Stop(MOTOR_STOP_00);
            break;

        case 6:
            MotorA_SetSpeed(-300);
            break;

        case 7:
            MotorA_Stop(MOTOR_STOP_11);
            break;

        default:
            MotorA_Stop(MOTOR_STOP_00);
            step = 0;
            return;
    }

    step++;
    if (step >= 8) {
        step = 0;
    }
}

int main(void)
{
    SYSCFG_DL_init();

    Motor_Init();

    while (1) {
        if (Key1_PressedOnce()) {
            test_stop_mode_next_step();
        }
    }
}
```

按键顺序：

正转300 → 00停
正转300 → 11停
反转300 → 00停
反转300 → 11停

## 测试 4：编码器正反转计数验证

用途：确认三个现象：

1. 转动时 count 变化
2. 正反转 count 方向相反
3. 停止时 count 基本不乱跳

你已经测通了。之后换其他电机时可以继续用这个。

```
#include "ti_msp_dl_config.h"
#include "motor.h"
#include "key.h"
#include "encoder.h"

static void test_encoder_next_step(void)
{

            Encoder1_ClearCount();
            MotorA_SetSpeed(200);
            break;

        case 1:
            MotorA_Stop(MOTOR_STOP_00);
            break;

        case 2:
            Encoder1_ClearCount();
            MotorA_SetSpeed(-200);
            break;

        case 3:
            MotorA_Stop(MOTOR_STOP_00);
            break;

            MotorA_Stop(MOTOR_STOP_00);
            step = 0;
            return;
    }

    step++;
    if (step >= 4) {

    }

int main(void)
{
```
